# FC Pay Calendar

쿠팡 FC 근무일을 달력에 입력해 예상 급여를 계산하는 정적 웹앱입니다.

## 기능

- 날짜별 근무 유형(기본, 연장, 특근, 특근+연장, 보건/특수병가)을 즉시 저장
- 월별 근무 기록과 계산 기준을 브라우저 `localStorage`에 자동 저장
- 보건/특수병가 일수에 따른 기본급 일할 계산 및 만근보너스 자동 반영
- 2026년 공휴일 표시, 일요일 빨간색·토요일 초록색 표시
- 지난달 명세서의 지급 합계와 소득세를 이용한 소득세·지방소득세 추정

## 실행

별도 설치가 필요 없습니다. `index.html` 파일을 브라우저로 열면 됩니다.

## 세금 추정 안내

소득세는 이번 달 지급 합계 × (지난달 소득세 ÷ 지난달 지급 합계) × 원천징수 비율로 계산합니다. 실제 원천징수액은 부양가족, 자녀, 비과세 항목, 상여 처리 등에 따라 달라질 수 있습니다.
